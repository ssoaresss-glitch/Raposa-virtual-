# Raposa Virtual
Protótipo web para Safari, Node.js 22, sem dependências. `npm start` inicia o servidor. Testar voz usa síntese local do navegador e animação aproximada, sem IA. Conversar só é ativado quando OPENAI_API_KEY e APP_PASSWORD estiverem configuradas no servidor. Nunca publique chaves. A API é cobrada separadamente do ChatGPT; não compartilha memória nem conversas. Em Render, use plano free, build `npm --version`, start `npm start`. A sessão do navegador tem limite de 15 minutos, não é garantia de cota de cobrança. Configure limites na conta API. Usuário para acesso protegido: raposa.
